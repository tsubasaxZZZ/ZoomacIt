## Swift とは

Swift は、Apple が 2014 年の WWDC で発表した汎用プログラミング言語です。当初は iOS / macOS 向けのアプリ開発を Objective-C から置き換えるために設計されましたが、現在では Linux でも動作し、サーバサイドや組み込み向けにも使われています。本書執筆時点(2026 年)の最新版は **Swift 6.0** で、ZoomacIt もこのバージョンで書かれています。

Swift の設計思想は「**安全(safe)・高速(fast)・表現豊か(expressive)**」の三本柱です。とくに *安全* の面では、`null` 参照を型システムで排除する Optional、データ競合をコンパイル時に検出する strict concurrency、配列の境界チェックなど、実行時エラーが起きにくい仕組みが言語レベルで組み込まれています。

> **NOTE**
> Java 経験者にとって、Swift は「Kotlin と Rust の中間」に位置する言語と言えます。Kotlin のように null 安全と簡潔な構文を持ちつつ、Rust のように所有権・並行性をコンパイル時に検査する厳密さも備えています。

## Java と Swift の俯瞰的な対応

最初の段階では、両言語の対応関係をざっくり頭に入れておくだけで十分です。詳細な文法は Part II の各章で深掘ります。

| 観点 | Java | Swift |
|---|---|---|
| パラダイム | オブジェクト指向 + 関数型 | オブジェクト指向 + 関数型 + プロトコル指向 |
| 実行環境 | JVM | ネイティブコード(LLVM) |
| 型システム | 静的型 + nullable | 静的型 + Optional + strict concurrency |
| メモリ管理 | GC | ARC(自動参照カウント) |
| 値型 / 参照型 | 参照型のみ(プリミティブ除く) | **struct = 値型 / class = 参照型** を選ぶ |
| 継承 | クラス単一継承 + interface 多重実装 | クラス単一継承 + protocol 多重適合 |
| ジェネリクス | 型消去 | 完全な型情報保持 + Opaque Types |
| 並行性 | `synchronized` / `Thread` / `CompletableFuture` | `async`/`await` + `actor` + `Sendable` |
| ラムダ / 無名関数 | ラムダ式 | クロージャ(capture list `[weak self]` あり) |

この表のうち、**太字で示した「struct と class の使い分け」「Sendable」「capture list」** は Swift 特有で、本教材で重点的に扱う項目です。これらは Java の経験から類推しにくく、ZoomacIt のコードを読み解くときの鍵にもなります。

## なぜ ZoomacIt のコードを教材にするのか

プログラミング言語を学ぶとき、教科書に載っている小さな擬似コードだけでは「実プロダクトでこの機能はどう使われるのか」がつかみにくいものです。本教材は **動作する実プロダクト(ZoomacIt)のコード** を題材にすることで、文法と設計の両方を同時に学べるよう構成しています。

ZoomacIt は次の特徴を持つため、Swift 学習の素材として適しています。

**第一に、外部依存がありません。** Swift Package Manager で何かを取り込んだり、CocoaPods で依存を解決したりする必要がなく、`make build` だけで完結します。学習者は依存ツリーに惑わされず、**Swift の言語仕様と Apple の標準フレームワーク** だけに集中できます。

**第二に、Swift 言語機能の網羅性が高いコードベースです。** 値型と参照型の使い分け(`Stroke` struct vs `DrawingState` class)、クロージャと weak capture(`AppDelegate` のホットキーハンドラ)、`async`/`await` と `@MainActor`(`BreakTimerWindowController`)、Carbon API への C 言語橋渡し(`HotkeyManager`)など、入門から応用までの題材が一つのプロジェクトに揃っています。

**第三に、設計ドキュメントが実装と同期しています。** リポジトリの [`design/`](../../design/) 配下に `ARCHITECTURE.md`、`Draw.md`、`Zoom.md` などの設計書が置かれており、「なぜこう実装したか」を追えます。教材ではこれらを適宜引用し、文法学習を「単なる構文の暗記」で終わらせません。

## 学習のゴール

本教材を読み終えると、次のことができるようになります。

1. **Swift の文法を Java の知識と対応づけて読める**(Part II)
2. **macOS アプリ特有の AppKit / SwiftUI / 並行性パターンが読める**(Part III)
3. **ZoomacIt 自体を改修できる** — 新しいペン色を追加したり、新機能を実装したりできる(Part IV)

各 Part の終わりには「次に読む章」へのリンクがあるので、迷わず進めます。

## 学習の進め方

Part I は導入なので、3 章とも順に読んでください。Part II 以降は **🟢 マークの章は流し読み**(Java と本質的に同じ)、**🟡🔴 マークの章は段落を読み込む** スタイルで進めると効率的です。

各章の構造は次のとおり共通化されています。

- **チートシート**(🟢 章のみ): Java との対応表
- **解説本文**(🟡🔴 章のみ): 段落 + コードスニペット
- **ZoomacIt の実コードを読む**: ファイルパスと行番号を明記して、実コードから抜粋
- **ハンズオン**(任意): 5〜15 分で終わる章末ミニ課題
